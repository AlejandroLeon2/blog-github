# Netlify vs Vercel: ¿cuál elegir para tu blog?

Ambos son excelentes para blogs estáticos. La diferencia está en detalles que importan según tu caso de uso.

## Netlify

- Deploy por drag & drop (ideal para prototipos)
- Functions serverless incluidas
- Form handling nativo
- Split testing integrado
- Plan generoso: 100GB/mes gratis

## Vercel

- Edge network más agresiva
- Mejor soporte para SSR/ISR
- Analytics integrados (付费)
- Deploy previews con comentarios
- Plan generoso: 100GB/mes gratis

## ¿Cuándo elegir Netlify?

- Tu blog es 100% estático (Astro output: static)
- Querés form handling sin backend
- Preferís simplicidad sobre features

## ¿Cuándo elegir Vercel?

- Usás SSR o ISR
- Querés edge rendering
- Tu proyecto puede crecer a una app más compleja

## Veredicto

Para un blog estático con Astro: **da igual**. Ambos son excelentes. Elegí el que ya conozcas o el que tenga mejor precio para tu caso.
